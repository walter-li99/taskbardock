# taskbardock

#### 介绍
它的功能是在windows任务栏上放一个自定义样式的图标。点击图标，会将自定义文件夹里的快捷方式，以菜单的形式在图标位置展开。这样，任务栏原本多个相同类别的程序图标就能变成一个自定义图标了。节省任务栏位置。

#### 安装教程

不用安装。直接执行exe就可以。
程序内部可以设置是否开机启动。

#### 使用说明

1.建立一个文件夹。
2.将同类图标复制进去。
3.打开taskbardock程序。在程序内添加这个文件夹，选择图标（可选），设置开机启动（可选）。就ok了
